✏️ Edit Custom Letters

Edit the letters to be used in games. The default English alphabet is shown. You can add or remove any letters as needed.

💡 Tip: Separate letters with commas. Spaces will be automatically removed.
Example: A,B,C,X,Q

⚙️ Custom Scoring System

You can set separate scores and acceptance settings for each word length. Default: 2-letter words = 2 points, 3-letter = 3 points, etc.

⚠️ Important: Words of unchecked lengths will not be accepted!

📦 Box-Based Letter Output

ℹ️ How Does It Work?

Orange boxes (vowels) and purple boxes (consonants) define which letters can appear. Click each box to select which letters can appear in that box.

🟠 Vowel Letter Boxes (3 boxes)

🟣 Consonant Letter Boxes (5 boxes)

💡 Tip: Letters inside boxes are randomly selected during the game. Empty boxes use the default letter distribution.
